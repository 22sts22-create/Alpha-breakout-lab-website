ALPHADESK

Multi-Stock Strategy Simulator

Run a moving-average crossover across a portfolio on simulated prices or your own Stooq CSV data. See every entry, exit, and P&L — and compare MA settings side by side — before you risk a single dollar.

📄 Educational simulator · Not financial advice · Past results never guarantee future returns

1. Choose your data

Simulated — AlphaDesk generates realistic price history for each ticker automatically. Fastest way to explore.

Upload CSV — use real historical prices from Stooq (free, no signup). On Stooq, search a symbol, open its page, and use the "Download data in csv" link. One file = one ticker. The file needs a Date column and a Close column — Stooq's default export works as-is.

2. Set the strategy

Pick three moving averages — Fast, Mid, Slow (they must increase). A buy fires when they stack bullish; an exit fires when Fast crosses below Mid.

3. Set capital & risk

Enter starting capital and how much (as a %) to allocate to each stock.

4. Run & read the results

  • The equity curve plots portfolio value over time, with entry (●) and exit (◆) markers color-matched to each ticker.
  • Per-stock breakdown shows each ticker's return, P&L, and trade count.
  • The trade log lists every buy and sell with its P&L.

Compare mode

Switch to Compare MA to test up to 5 different MA combinations on a single stock — the fastest way to see which settings would have performed best on that name.
